## Goal
For non-wiki / softAmbiguous+ctx / Latin-foreign strangers: discover **public registry** hits by name + optional context and turn them into **evidenced candidates** (`sourcesPreview` with https URLs) so `decideStage` can return `candidates` instead of empty `need_context` when context was provided.

## What shipped

### `api/lib/stageB.js` → `registryDiscover({ q, ctx, signal, limit })`
Returns `{ candidates, sources, notes }`.

| Registry | Endpoint (fixed https hosts only) |
|----------|-----------------------------------|
| ORCID | `https://pub.orcid.org/v3.0/expanded-search/?q=…` Accept JSON |
| Open Library | `https://openlibrary.org/search/authors.json?q=…` |
| VIAF | `https://viaf.org/viaf/AutoSuggest?query=…` (short timeout; skip on fail) |
| Wikidata | `https://www.wikidata.org/w/api.php?action=wbsearchentities…` (429 → empty) |

- SSRF: **allowlisted hosts only**; never fetches user URLs / Sync.me / Truecaller
- AbortSignal + per-call timeouts via `AbortSignal.any`
- Candidates pass `filterEvidencedCandidates` before return

### Sample candidate shape
```json
{
  "id": "viaf-75121530",
  "label": "Albert Einstein, 1879-1955",
  "why": ["VIAF registry", "ctx: Princeton", "ctx: USA"],
  "sourcesPreview": [
    { "kind": "VIAF", "title": "Albert Einstein, 1879-1955", "url": "https://viaf.org/viaf/75121530/" }
  ],
  "score": 0.9
}
```

### Wire in `api/lookup.js`
**Trigger (`wantStageB`)** after wiki path, only when:
- `!wikiExactHit` **and**
- `(ctx.any || latinForeign)`
  (softAmbiguous+ctx covered by `ctx.any`)

**KEPT intact:**
- Early `need_context` for `softAmbiguous && !ctx.any && !forceGoogle && !wikiExactHit` (celebs still dossier via wikiExact)
- CORS / scrub / SSRF / AbortSignal / POST identifier body-only rules untouched

**Flow:**
1. SoftAmbiguous + ctx + !forceGoogle → **await B first**; if ≥2 evidenced → early `candidates` via `decideStage` + `attachOrchestratorFields` (skip Gemini)
2. Else run B **in parallel** with `googlePath` when Gemini runs; if Gemini skipped (429/budget) **still run B**
3. Merge `stageB.sources` into sources list; append B candidates before `decideStage`, re-gated with `filterEvidencedCandidates`
4. `strongConfirm` aligned to `canCommitWithoutFocus` (threshold **0.75**) using B top candidate + merged sources
