## Changes (`api/lookup.js` only)

### P0-1 Abuse protection on `/api/lookup` (handler ~2498+)
- **CORS allowlist** (`ALLOWED_ORIGINS` / `isAllowedOrigin` / `setCors` ~2435–2462):  
  `https://akvot-simple-demo.vercel.app`, `http://localhost:3000`, `http://127.0.0.1:3000`, plus `akvot-simple-demo*.vercel.app` previews.  
  Reflects allowed `Origin` (never `*`). Unknown `Origin` → **403**.
- **Methods**: OPTIONS → 204; non-GET → **405** + `Allow: GET, OPTIONS`.
- **Rate limit** (`checkRateLimit` / `clientIp` ~2465–2496): in-memory Map, **20 req / 10 min / IP** (`x-forwarded-for` first hop or `x-real-ip`). Exceed → **429** + `Retry-After`. Comment notes serverless memory is best-effort / not shared.
- **Optional token**: if env `AKVOT_DEMO_TOKEN` is set, require `x-akvot-token` header or `?token=`; if unset, skipped (existing deploys keep working). Documented in one-line comment near check. CORS `Allow-Headers` includes `x-akvot-token`.
- Streaming / `nocache` query params untouched.

### P0-2 SSRF hardening (`scanPage` / page fetches)
- Existing helpers retained/used: `isPrivateOrBlockedHost`, `assertSafePublicHttpsUrl`, `isSafeFetchUrl` (~150–196).
- New **`safeFetchPage`**: `redirect: 'manual'`, re-validates each `Location` (max 3), timeout via `AbortSignal`, blocked → `null`.
- **`scanPage`**: pre-check with `assertSafePublicHttpsUrl` (https-only remote); fetches via `safeFetchPage` (no `redirect: 'follow'`).
- **`resolveGroundingUrl`**: still only initiates to fixed Google grounding host; switched GET path to **manual** redirects + `assertSafePublicHttpsUrl` on targets (no blind follow to internals).
- Trusted fixed-host Wikimedia / Bing / Gemini fetches left alone.
