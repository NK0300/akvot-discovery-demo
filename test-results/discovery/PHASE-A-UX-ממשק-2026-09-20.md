## 0. Product lock (UX)

עקבות Discovery = **מרחב חקירה ציבורי**, לא People Search.

| Mode | What user sees | What we NEVER claim |
|------|----------------|---------------------|
| **Discovery Mode** (default) | Findings · Evidence · Facets · progressive counts | "זה האדם" · identity commit · fake certainty |
| **Entity Mode** (entered only with evidence) | Entity card · provenance · conflicts · next actions | Absolute identity without Evidence |

**INFORMATION ≠ IDENTITY** · same name ≠ same person · UNKNOWN ≠ FALSE · soft CTA stays (`בחר כמועמד להמשך`) if Entity Mode shows candidates.

## 1. Two modes — entry rules

### Discovery Mode (home default)
- Primary: single query **«מה אתם מחפשים?»** (progressive disclosure; current 7-field OPS = legacy Entity until migrate)
- Secondary: optional hints (org / city / site) behind «הוסף הקשר»
- Results stream: Findings feed + Facet rail + Progress strip
- No dossier chrome · no portrait · no «ביטחון: גבוה» identity chip

### Entity Mode (narrow / commit path)
- Enter **only** when: user picks a Finding that has entityRefs **or** Core returns uiState with Acc-safe binding
- Exit: «חזרה לגילוי» → Discovery Mode with session preserved
- Candidates: soft CTA only · NEVER absolute «זה האדם»
- Forbidden QIDs stripped before render (Acc SoT) — UI must not rehydrate stripped ids

### Mode switch wire
```
[READY Discovery]
    → query → [Discovery Loading / Progressive]
    → findings+facets → [Discovery Results]
    → user narrows facet OR opens finding
    → (optional) [Entity Mode] if evidence-backed
    → back → Discovery (same sessionId)
```

## 3. Screens & components

### 3.1 Progress strip (progressive)
- `status`: running | partial | complete | failed_soft
- Counts: findingsN · providersDone/providersTotal · facetKeysN
- Soft errors: «מקור X איטי — ממשיכים» (never blank fatal for one provider)
- Cancel: AbortSignal (reuse current cancel pattern)

### 3.2 Finding card
- Title · kind badge · 1-line summary
- **«מאיפה יודעים?»** expands Evidence list: provenanceUrl · provider · quote · retrievedAt
- scoreFinding = ranking of **finding usefulness**, labeled «רלוונטיות ממצא» — **not** «ביטחון זהות»
- Actions: Open source · Narrow by this facet · (if entityRefs Acc-safe) «פתח ישות»

### 3.3 Facet rail
- Dynamic facets from server (org, site, role, place, year, provider, kind)
- Multi-select · server `POST .../narrow`
- Counts update after narrow
- Empty facet: hide, don't show 0-noise

### 3.4 Provenance panel («מאיפה יודעים?»)
- Mandatory on every Finding and every Relationship edge
- Template: מקור · כתובת · ציטוט · זמן שליפה · ספק
- Missing provenanceUrl → Finding must not render (S3 drop already)

### 3.5 Relationship / soft graph
- Edges only with Evidence
- Label: «קשר מדווח במקור» — never «אותו אדם»
- Pivot: click node → new Discovery narrow / new Finding focus

### 3.6 Entity Mode (reuse + harden current states)
| Current uiState | Discovery mapping |
|-----------------|-------------------|
| need_context | stay · ask hints · 0 faces |
| candidates | soft CTA · Acc scrub · no absolute language |
| dossier | Entity Mode only if Acc-safe · provenance first |
| thin | UNKNOWN · next actions · no invented certainty |

## 4. Copy & Acc UX invariants

| Forbidden in UI | Required |
|-----------------|----------|
| «זה האדם» / absolute identity | Soft CTA / «המשך עם ממצא» |
| Confidence % as identity | Finding relevance vs Evidence count |
| Portrait without Acc-safe entity | Empty portrait / «אין דיוקן מאומת» |
| Hiding Finding for uncertainty | Show Finding + UNKNOWN entity binding |
| Forbidden QID display | Rely on server scrub; belt: if id in strip list, don't paint |

**Acc surfaces (UX must not reintroduce stripped ids):** findings · candidates · facets value ids · graph nodes · cache-rendered HTML.

## 5. Progressive UX contract (client ↔ API)

Align with Server progressive API:

| Client action | API |
|---------------|-----|
| Submit query | `POST /api/discovery/sessions` |
| Live updates | SSE `.../events` or poll `GET .../sessions/:id` |
| Facet narrow | `POST .../narrow` |
| Cancel | abort session / AbortSignal |

UI states while running:
1. Skeleton + progress strip  
2. Partial findings as they arrive (append, don't jump-reorder aggressively)  
3. Facets may lag one tick — show «מעדכן מסננים…»  
4. `failed_soft`: banner + keep partial results
